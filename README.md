# IPPN | Ciência para a indústria

Portfólio estático atualizado, com página principal e páginas individuais dos 20 docentes.

## Publicar no GitHub Pages

1. Extraia este ZIP.
2. Crie um repositório no GitHub e envie **o conteúdo da pasta**, com `index.html` na raiz. Inclua também `assets` e `.nojekyll`.
3. Em Settings → Pages, escolha Deploy from a branch, branch `main` e pasta `/ (root)`. Salve.
4. O endereço será https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/.

Não precisa instalar programas nem executar build. As páginas usam caminhos relativos para funcionar em um repositório do GitHub Pages.

O conteúdo deve ser revisado e aprovado pelos docentes antes da divulgação institucional. Links da Central Analítica, Lattes e ORCID levam a sites externos.
